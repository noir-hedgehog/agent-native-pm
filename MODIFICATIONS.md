# Mesh Modifications

Mesh began from Plane Community Edition and the AgentPM orchestration MVP.
This repository modifies Plane to provide an agent-native collaboration
console and adds Agent identity, policy, MCP, project-member management,
execution orchestration, and audit capabilities.

## Upstream baseline

- Plane repository: https://github.com/makeplane/plane
- Imported Plane commit: `9fa707b26077b5797f6435cdf346e43daef4d2af`
- Current merged Plane release: `v1.3.1`
- Initial Mesh modification baseline: 2026-07-21

Detailed product changes are tracked in this repository's Git history and
`CHANGELOG.md`.
